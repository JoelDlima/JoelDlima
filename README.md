## Selected work

Most of my systems work lives in private repos (client and coursework constraints) — happy to walk through any of it on request.

**AgroProfit** — AI agricultural market platform `🔒`
React · TypeScript · Supabase · Gemini API. Aggregates real-time government *mandi* prices via automated sync pipelines, then adds a Gemini advisory layer so farmers know both the price and what to do about it. Recognized at the Lenovo LEAP Culmination Event.

**Smart Eco-Well** — IoT water-quality monitoring `🔒`
ESP32 with TDS, turbidity, and pH sensors over I2C/SPI/UART, streaming live readings over WiFi to a cloud database and dashboard. Remote water safety without a site visit.

**Palliative Care** — remote patient monitoring `🔒`
ESP32 with SpO₂, heart-rate, ECG, and fall-detection sensors feeding continuous vitals to a cloud dashboard — role-based access, threshold-triggered emergency alerts, geospatial tracking, and an AI caregiver assistant.

**Lead Genius** — lead-generation pipeline `🔒`
