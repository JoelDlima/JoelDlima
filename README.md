## 🧠 About

> Hardware people who can ship a frontend are rare. So are web devs who can read a datasheet. I'm trying to be both.

Fourth-year **Electronics & Computer Engineering** student at Agnel Institute of Technology and Design, Goa — **CGPA 9.7**, graduating 2027. I take data from bare pins on an ESP32 and carry it all the way to a dashboard a farmer, a nurse, or a driver actually uses.

- 🔌 I wire up **ESP32** sensor arrays, then build the cloud dashboard that makes their data useful
- 🚗 **Software Engineering Intern @ Visteon** (Jul–Oct 2026) — automotive electronics & software, PPO track
- 🚀 4 months of production React at **EpicForce** — rebuilt the [InnerVerse](https://myinnerverse.in) dashboard, scoped its WordPress → React/Node/Supabase migration
- 🌾 Recognized at the **Lenovo LEAP Culmination Event** for AI-driven agricultural innovation
- 🎯 Currently deepening embedded **C/C++** and automotive-grade engineering practice
- 📍 Mapusa, Goa, India
